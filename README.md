# Tomas verktygsuppgift

Den här uppgiften visar att jag kan hantera **filsystemet**, **terminalen**, ***Visual Studio Code*** och ***GIT/Github***.

## Använda GIT kommandon
* **git init** Skapar ett repository i mappen jag är i.
* **git add** GIT add lägger till filer till staging area, där de väntar på **commit**. **git add .** betyder alla filer i nuvarande mapp läggs till.
* **git commit** sparar alla ändringar i staging area till en ny commit i vår repository. **git commit -m "message"** skickar med commit-meddelandet direkt, annars poppar det upp en editor där man kan skriva meddelandet istället. Första **commit** efter **git init** är en initial commit, som blir startpunkten för repots historik.
* **git status** visar nya och ändrade filer i staging area och som behöver läggas till om de ska komma med i nästa **commit**.
